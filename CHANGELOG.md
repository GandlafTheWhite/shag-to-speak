# Changelog - ShagToSpeak

## [1.0.2] - 2024-12-01

### 🔧 Исправления

#### Проблема 1: Ошибка "failed to get exercises" после обновления платформы

**Причина:** После deployment новой версии у пользователя оставался старый закэшированный код, что вызывало конфликты между старым frontend и новым backend API.

**Решение:**
- ✅ Добавлено автоматическое версионирование приложения (`src/version.ts`)
- ✅ При обновлении версии автоматически очищаются все кэши Service Worker
- ✅ localStorage очищается (кроме критичных данных: userId и auth_token)
- ✅ Service Worker обновляется без подтверждения пользователя
- ✅ Страница автоматически перезагружается с новой версией

**Файлы:**
- `src/version.ts` - новый файл с версионированием
- `src/main.tsx` - добавлена проверка версии при запуске
- `public/service-worker.js` - обработка сообщений об очистке кэша

**Как работает:**
```typescript
// При каждом запуске приложения
1. Проверяется APP_VERSION в localStorage
2. Если версия отличается:
   - Очищается localStorage (кроме auth данных)
   - Удаляются все кэши SW
   - Обновляется Service Worker
   - Перезагружается страница
3. Пользователь получает актуальную версию
```

#### Проблема 2: Индикаторы загрузки не видны на мобильных устройствах

**Причина:** React batching объединял setState вызовы, и UI не успевал отрисовать loading screen перед началом загрузки упражнений.

**Решение:**
- ✅ Изменена последовательность setState в `handleCategorySelect()`
- ✅ `isLoadingExercises` устанавливается в `true` **ДО** смены view
- ✅ `currentView` переключается на `'exercise'` сразу
- ✅ `exercises` очищается перед загрузкой новых данных
- ✅ При ошибке загрузки возврат на `'menu'` вместо зависания

**Файлы:**
- `src/components/LearnWords.tsx`

**Изменения в коде:**
```typescript
// ДО (не работало):
const handleCategorySelect = (category: string) => {
  setSelectedCategory(category);
  loadExercises(category); // async, loading устанавливался внутри
};

// ПОСЛЕ (работает):
const handleCategorySelect = (category: string) => {
  setSelectedCategory(category);
  setIsLoadingExercises(true);        // 1. Сразу loading
  setCurrentView('exercise');          // 2. Переключаем view
  loadExercises(category);             // 3. Загружаем данные
};
```

**Результат:**
- Пользователь видит полноэкранный индикатор с текстом:
  - "Генерируем упражнения"
  - "Подбираем задания специально для тебя..."
  - "Это может занять до 30 секунд" ⏱️

#### Проблема 3: Системные сообщения закрывают управление на мобильных

**Причина:** Toast уведомления появлялись сверху экрана, закрывая header с кнопками навигации. Не было визуального индикатора времени до автозакрытия.

**Решение:**
- ✅ Изменено позиционирование: теперь toast **всегда снизу экрана**
- ✅ Добавлен Progress Bar с обратным отсчётом (5→4→3→2→1)
- ✅ Таймер обновляется каждые 100ms для плавности
- ✅ Автоматическое закрытие через 5 секунд
- ✅ Адаптивная ширина: на мобильном - full width, на десктопе - 420px

**Файлы:**
- `src/components/ui/toast.tsx` - позиционирование viewport
- `src/components/ui/toaster.tsx` - компонент с таймером

**Как работает:**
```typescript
// Новый компонент ToastWithTimer
1. При появлении toast запускается таймер на 5000ms
2. Progress Bar уменьшается от 100% до 0%
3. Счётчик показывает секунды: 5 → 4 → 3 → 2 → 1 → 0
4. Toast автоматически закрывается
5. Пользователь может закрыть вручную крестиком
```

**Визуально:**
```
┌─────────────────────────────────────┐
│ ✓ Упражнения сохранены              │
│   Ты молодец!                        │
│   ██████░░░░░░░░░░░░░░░░░░░░  3s    │
└─────────────────────────────────────┘
        ↑ внизу экрана
```

export function checkAndMigrateVersion(): boolean {

    // Очистка данных

}
